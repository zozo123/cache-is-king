From research to workflow

Persistence is not residency.

Blacksmith insight

Do not serialize what can stay put.

Persistent builder state can retain cache mounts and avoid repeated cache transfer. But persistent bytes can still be physically cold.

cache_ext insight

Do not retain scans over hot objects.

One-size-fits-all page eviction may retain streaming Docker work while evicting the small compiler hot set the next build needs.
